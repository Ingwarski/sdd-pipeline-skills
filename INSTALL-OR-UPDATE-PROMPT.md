# Єдиний промпт для встановлення або оновлення

Скопіюйте в локального агента з доступом до файлів і термінала:

```text
Встанови або онови SDD Pipeline Skills для локальних Codex і Claude Code з https://github.com/Ingwarski/sdd-pipeline-skills.

Визнач ОС. Перед змінами перевір Python 3.9+; якщо його немає, зупинись і дай офіційне посилання. Знайди постійний клон у звичних папках проєктів за актуальним origin, старим `Ingwarski/codex-skills` або назвою `Codex Skills` / `Codex SDD Skills`; не скануй увесь диск і не перезаписуй сторонні Git-зміни.

- Клону немає: клонуй актуальний репозиторій у постійну папку та запусти `./install.sh --all` (macOS/Linux) або `.\install.ps1 -All` (Windows).
- Клон є: встанови актуальний origin і онови чисту `main` лише fast-forward, щоб запускати новий updater. Перевір керовані та підтверджені проєктні папки скілів на `communications-audit` і `issue-happypro-certificate`. Якщо вони є, запусти `./update.sh --all` / `.\update.ps1 -All`, додавши кожну додаткову папку через `--cleanup-dir PATH` / `-CleanupDir PATH`; видали обидва скіли назавжди, без backup/Trash. Якщо їх немає, запусти звичайне `./update.sh --all` / `.\update.ps1 -All`.

Використовуй лише скрипти репозиторію та правила `AGENTS.md`; не змінюй інші скіли. Наприкінці перевір 13/13 `SKILL.md`, відсутність обох застарілих скілів у перевірених папках і коротко повідом шлях клону, коміт, перевірені папки, помилки та чи потрібен перезапуск.
```

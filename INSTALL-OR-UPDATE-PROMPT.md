# Єдиний промпт для встановлення або оновлення

Скопіюйте в локального агента з доступом до файлів і термінала:

```text
Встанови або онови SDD Pipeline Skills для локальних Codex і Claude Code з https://github.com/Ingwarski/sdd-pipeline-skills.

Визнач ОС. На python.org знайди latest stable Python 3 і порівняй з активним Python. Якщо Python відсутній або старіший, встанови latest stable лише з python.org: цей промпт це дозволяє. Виконай потрібне системне підтвердження, перезапусти термінал/агент і перевір нову активну версію; якщо це не вдалося, зупинись і поясни.

Знайди постійний клон у звичних папках проєктів за актуальним origin, старим `Ingwarski/codex-skills` або назвою `Codex Skills` / `Codex SDD Skills`; не скануй увесь диск і не перезаписуй сторонні Git-зміни.

- Клону немає: клонуй актуальний репозиторій у постійну папку та запусти `./install.sh --all` (macOS/Linux) або `.\install.ps1 -All` (Windows).
- Клон є: встанови актуальний origin, перевір чисту `main`, виконай `git fetch origin main`, перевір 13/13 `SKILL.md` і керовані/підтверджені проєктні папки на `communications-audit` та `issue-happypro-certificate`. Якщо `HEAD = origin/main`, 13/13 валідні й обох застарілих скілів немає, повідом commit «skills already up to date» та зупинись: не запускай installer або updater. Якщо застарілі скіли є, запусти `./update.sh --all` / `.\update.ps1 -All`, додавши кожну додаткову папку через `--cleanup-dir PATH` / `-CleanupDir PATH`; видали їх назавжди, без backup/Trash. Якщо клон відстає — запусти той самий updater. Якщо клон актуальний, але 13/13 невалідні — запусти `./install.sh --all --repair` / `.\install.ps1 -All -Repair`.

Якщо `main` не чиста, попереду/розходиться з origin або GitHub недоступний, зупинись без змін і поясни причину. Використовуй лише скрипти репозиторію та правила `AGENTS.md`; не змінюй інші скіли. Наприкінці перевір 13/13 `SKILL.md`, відсутність обох застарілих скілів у перевірених папках і коротко повідом шлях клону, коміт, перевірені папки, помилки та чи потрібен перезапуск.
```

# Промпт для оновлення SDD Pipeline Skills

Скопіюйте текст нижче в Codex або Claude Code.
Увага: він передбачає остаточне видалення двох бізнес-скілів, зокрема їхніх локальних змін, без резервної копії.

```text
Онови мої SDD Pipeline Skills і остаточно видали випадково встановлені бізнес-скіли:
- communications-audit
- issue-happypro-certificate

Не зберігай, не архівуй, не перенось у резервну папку чи Кошик жоден із цих двох скілів у папках, які очищаєш. Видаляй також змінені копії та пошкоджені посилання. Запис про інше джерело встановлення не є винятком.

Актуальний репозиторій: https://github.com/Ingwarski/sdd-pipeline-skills
Стара адреса: https://github.com/Ingwarski/codex-skills
Старі назви локального клону: Codex Skills або Codex SDD Skills.

1. Знайди фактичний SDD-клон. Перевір origin, гілку та локальні зміни. Визнач папки встановлення Codex і Claude Code, локальні папки скілів у моїх проєктах і підтверджені старі SDD-клони.

2. Для підтвердженого клону встанови origin https://github.com/Ingwarski/sdd-pipeline-skills.git. Онови чисту гілку main через git pull --ff-only. Не скидай історію й не перезаписуй сторонні зміни. Якщо Git блокує оновлення, поясни причину та не заявляй про завершення.

3. Прочитай актуальні README.md, AGENTS.md або CLAUDE.md, skills-manifest.json і retired-skills.txt. Запусти штатне оновлення:
   - macOS/Linux: ./update.sh --all
   - Windows: .\update.ps1 -All

4. Передай кожну додаткову підтверджену папку скілів через --cleanup-dir або -CleanupDir. Це стосується .agents/skills, .codex/skills, .claude/skills у моїх проєктах, а також skills/ у старих SDD-клонах. Не передавай корінь диска чи всю папку проєктів. Не обходь посилання до зовнішніх репозиторіїв: окрему копію видаляй лише в явно включеній папці.

   Якщо потрібне лише очищення, актуальний ./install.sh --all --retire-only або .\install.ps1 -All -RetireOnly видаляє ці два скіли без зміни SDD-посилань. Новий оновлювач сам виконує це очищення перед перевіркою сторонніх локальних змін у Git.

5. Перевір, що обидва бізнес-скіли фізично відсутні в усіх цих папках. Штатний скрипт також видаляє резервні копії, створені попереднім SDD-оновлювачем для цих встановлень. Якщо видалення не вдалося, покажи точний шлях і помилку. Не називай очищення завершеним.

6. Не встановлюй приватний бізнес-репозиторій. Не змінюй решту скілів, назви чи функції 13 SDD-скілів. Сторонній to-prd не чіпай: SDD використовує to-sdd-prd.

7. Повтори ./install.sh --all --repair або .\install.ps1 -All -Repair із тими самими папками очищення. Перевір 13/13 SKILL.md, відсутність обох бізнес-скілів і відсутність нових резервних копій.

8. Коротко повідом: коміт і шлях клону; перевірені папки; що остаточно видалено; результат 13/13; будь-які залишки чи помилки; потребу в перезапуску.

Потрібне остаточне видалення локальних копій у визначених папках, а не переписування Git-історії. Не налаштовуй фонові чи автоматичні оновлення без мого окремого запиту.
```

# Промпт для оновлення SDD Pipeline Skills

Скопіюйте текст нижче в Codex або Claude Code.

```text
Онови моє встановлення SDD Pipeline Skills і прибери випадково встановлені бізнес-скіли зі старого спільного репозиторію.

Актуальне джерело: https://github.com/Ingwarski/sdd-pipeline-skills
Старе джерело: https://github.com/Ingwarski/codex-skills
Старі назви локальної папки: Codex Skills або Codex SDD Skills.
Бізнес-скіли, які більше не належать до SDD: communications-audit та issue-happypro-certificate.

1. Знайди фактичний локальний клон. Перевір Git origin, гілку, локальні зміни та наявні встановлення Codex і Claude Code. До оновлення запиши підтверджені старі шляхи клону та цілі встановлених посилань.

2. Якщо є локальні зміни, незапушені коміти або гілка не main, нічого не перезаписуй: поясни ситуацію та зупинись. Не використовуй примусове скидання, очищення робочого дерева чи видалення історії.

3. Для підтвердженого SDD-клону зміни origin на https://github.com/Ingwarski/sdd-pipeline-skills.git. Прочитай актуальні README.md, AGENTS.md або CLAUDE.md, skills-manifest.json і retired-skills.tsv. Якщо нових файлів ще немає, спочатку виконай безпечне оновлення через git pull --ff-only; у разі помилки зупинись.

4. Запусти штатне оновлення:
   - macOS/Linux: ./update.sh --all
   - Windows: .\update.ps1 -All

   Воно оновлює клон, відновлює встановлення та запускає очищення. Не копіюй скіли й не створюй власну логіку посилань або видалення.

5. Перевір очищення двох бізнес-скілів у клоні та відомих папках встановлення. Штатний скрипт видаляє підтверджені старі SDD-посилання, а незмінені копії переносить за межі активних папок скілів із резервною копією для відновлення.

   Якщо знайдено інші відомі папки встановлення, передай кожну через --cleanup-dir або -CleanupDir. Якщо старий клон уже відсутній, передавай --retired-source або -RetiredSource лише з підтвердженим абсолютним шляхом. Сама назва папки не доводить походження.

   За наявності REVIEW REQUIRED покажи точні шляхи та причину. Не видаляй змінені або непідтверджені копії без мого рішення та не оголошуй очищення завершеним.

6. Збережи сторонні скіли, незалежні встановлення з Custom Agent Skills і їхні записи походження. Не клонуй і не встановлюй приватний бізнес-репозиторій. Не змінюй назви 13 SDD-скілів, їхні функції чи спосіб виклику. Сторонній to-prd не чіпай: SDD використовує to-sdd-prd.

7. Повторно запусти ./install.sh --all --repair або .\install.ps1 -All -Repair. Перевір усі 13 SKILL.md через встановлені шляхи, відсутність пошкоджених SDD-посилань і повторного очищення вже прибраних копій.

8. Коротко повідом:
   - шлях клону, origin, гілку та коміт;
   - папки встановлення Codex і Claude Code та результат 13/13;
   - що прибрано, що навмисно збережено, де лежать резервні копії;
   - будь-які невирішені випадки та чи потрібен перезапуск.

Очищення стосується активних встановлень, а не старої Git-історії чи невідомих копій на диску. Не налаштовуй автоматичні оновлення, фонові процеси або розклад без мого окремого запиту.
```
